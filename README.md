## 🚀 Getting Started

Follow these steps to run FlyrankAi locally on your machine.

### Prerequisites
Make sure you have Node.js installed (v18.x or later recommended) along with `npm`.

### Installation
1.  **Clone the Repository:**
    ```bash
    git clone https://github.com/yourusername/capstone-FlyrankAi.git
    cd capstone-FlyrankAi
    ```
2.  **Install Dependencies:**
    ```bash
    npm install
    ```
3.  **Start the Development Server:**
    ```bash
    npm run dev
    ```
    *The app will be available at `http://localhost:5173`.*

4.  **Build for Production:**
    ```bash
    npm run build
    ```
