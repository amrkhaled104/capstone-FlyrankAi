# FlyrankAi

## 📌 Project Overview

FlyrankAi is a modern web application built with Next.js App Router, React 19, TypeScript, and Tailwind CSS.

### Key Features
- **Next.js App Router** with nested layouts and server components
- **TypeScript** for robust end-to-end type safety
- **Tailwind CSS v4** for modern utility-first styling
- Clean `src/` directory organization

---

## 🛠️ Tech Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Linting:** ESLint

---

## 🚀 Getting Started

Follow these steps to run FlyrankAi locally on your machine.

### Prerequisites
Make sure you have Node.js installed (v18.x or later, recommended v20+) along with `npm`.

### Installation
1. **Clone the Repository:**
   ```bash
   git clone https://github.com/yourusername/capstone-FlyrankAi.git
   cd capstone-FlyrankAi
   ```

2. **Install Dependencies:**
   ```bash
   npm install
   ```

3. **Start the Development Server:**
   ```bash
   npm run dev
   ```
   *The app will be available at `http://localhost:3000`.*

4. **Build for Production:**
   ```bash
   npm run build
   ```

5. **Start Production Server:**
   ```bash
   npm run start
   ```
